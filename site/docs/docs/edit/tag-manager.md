# Tag manager

**Tags › Manage tags** adds controls to create, rename, move and delete keyword tags.

- **Create**: name a new tag, anywhere in the tree.
- **Rename**: click the name.
- **Move**: drag a tag onto its new parent, or onto "top level".
- **Delete**: removes the tag from every photo.

Tags live in digiKam's database, so digiKam's database is backed up before each change. Renaming, moving or deleting a tag also rewrites the tag in the sidecar of every photo carrying it (or one of its sub-tags). That runs in the background, resumes after a restart, and backs each sidecar up first.

People tags, digiKam's internal tags and tags with face data are left to the People pages and to digiKam.

## Tag pictures

Each tag and person shows the photo chosen in digiKam ("Set as Tag Thumbnail"). To change it in iopix, show faces with ++f++ and click **use as badge**, or use the photo button on a person or tag in the info panel.

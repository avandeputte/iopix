# Ratings, captions and tags

## One photo

In the viewer's info panel, click a value to change it:

- **Rating**: the stars, or keys ++0++ to ++5++.
- **Title** and **caption**: click to edit, Enter to save.
- **Tags**: ++t++ opens the tag dialog with your recent tags first. Type to find a tag, or type `Parent/New tag` and Enter to create one.
- **Favorite**: ++l++.

## Many photos

Select photos, then use the selection bar:

- **Tag** adds or removes tags on all of them.
- **Edit** sets rating, title, caption and tags together.
- **Copy metadata** (two or more photos): choose the photo to copy from and the fields (rating, title, caption, keywords, location, date taken, creator and copyright).

## Metadata templates

**Settings › Metadata templates** defines templates with creator, copyright, contact and IPTC fields, written the way digiKam writes its templates. Apply one from the info panel or the Edit dialog. As in digiKam, applying a template sets every field, so empty fields clear.

## Place tags

**Settings › Editing › Place tags**, or **Add place tags from GPS positions** in the tag dialog, creates `Places/Country/Region/Town` tags from each photo's position and assigns them.

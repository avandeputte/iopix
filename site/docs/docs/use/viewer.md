# The photo viewer

Click any photo to open it full screen.

![The viewer with its info panel](/img/viewer.jpg){.shot}

## Moving around

- **Swipe** on a phone, or use the **arrow keys**.
- **Zoom and pan** with the wheel, a pinch or a double-click. Zoomed in far enough, iopix switches to the original file for full detail.
- A **film strip** of the neighbouring photos runs along the very bottom edge.
- **Slideshow** plays the current list.
- Videos play inline.

## The info panel

Press ++i++ or the info button. It shows everything known about the photo, and almost every value is a link to other photos with the same value:

1. your own **title and caption**,
2. **date**, **file**, **people**, **tags** and **place**,
3. **camera, lens and exposure** in small type,
4. **AI analysis** at the end: description, detected content, objects, text found in the picture, sharpness and similar photos.

The gear at the top of the panel (or **Settings › Display › Info panel**) chooses which sections show. The choice is saved with your account.

**Actions** holds everything you can do with the photo: download, share, add to an album, rotate, crop, adjust, move, rename, use as a folder cover, and more.

## Faces and objects

Press ++f++ to show face boxes with names, and ++o++ to show the boxes of detected objects. With editor rights, face boxes can be named, confirmed, adjusted or removed right there. See [Naming faces](../edit/faces.md).

## Sharing and downloading

**Share** opens the device's own share sheet with the picture attached where the browser supports it, or a menu of links otherwise. **Download** saves the original.

## Keys

| Key | Does |
| --- | --- |
| ++left++ ++right++ | previous, next |
| ++0++ to ++5++ | set the rating |
| ++l++ | favorite |
| ++i++ | info panel |
| ++t++ | tag |
| ++p++ | name the next unnamed face, or draw one |
| ++f++ / ++o++ | faces / objects |
| ++bracket-left++ ++bracket-right++ | rotate left / right |
| ++delete++ | move to the trash |
| ++escape++ | close |

All keys are on the [Keyboard shortcuts](../reference/keyboard.md) page.

# Keyboard shortcuts

## In the viewer

| Key | Does |
| --- | --- |
| ++left++ / ++right++ | previous / next photo |
| ++0++ … ++5++ | set the rating (0 clears it) |
| ++l++ | favorite |
| ++i++ | info panel |
| ++t++ | tag dialog, recent tags first |
| ++p++ | name the next unnamed face, or draw one |
| ++f++ | show or hide faces |
| ++o++ | show or hide detected objects |
| ++bracket-left++ / ++bracket-right++ | rotate left / right |
| ++delete++ | move to the trash (with Undo) |
| ++escape++ | close the viewer or a dialog |

## In grids

| Key | Does |
| --- | --- |
| ++shift++ + click | select a range |
| ++escape++ | clear the selection or close a dialog |

## Search

| Key | Does |
| --- | --- |
| ++enter++ | search the typed words everywhere |
| ++up++ / ++down++ | move through suggestions |

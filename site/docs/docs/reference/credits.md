# Credits

## digiKam

iopix exists because of [digiKam](https://www.digikam.org), the open-source photo manager by the KDE community. iopix is an independent project and is not affiliated with the digiKam team.

## Models

| Model | Used for | From |
| --- | --- | --- |
| SigLIP 2, CLIP, Jina CLIP | content search | Google, OpenAI, Jina AI |
| YOLOX | object detection | Megvii |
| RapidOCR | text in photos | RapidAI (PaddleOCR models) |
| YuNet, SFace | face detection and grouping | OpenCV Zoo |
| SCRFD, ArcFace, RetinaFace | face detection and grouping (larger models) | InsightFace |
| BLIP | photo descriptions | Salesforce |
| GeoNames | place names | geonames.org (CC BY 4.0) |

## Libraries and tools

FastAPI, Pillow, ONNX Runtime, exiftool by Phil Harvey, ffmpeg, libjpeg-turbo, libheif, Leaflet and OpenStreetMap.
